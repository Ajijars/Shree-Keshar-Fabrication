# Replace these demo images with your real photos

Place your images in this folder using these filenames (or update paths in `src/data/siteData.js`):

| File | Purpose |
|------|---------|
| `hero.jpg` | Hero background — Viththal / Rath / Dindi procession |
| `logo.png` | Business logo |
| `shop.jpg` | Workshop / shop photo |
| `about.jpg` | About section image |
| `owner-prabhakar.jpg` | Photo of Prabhakar Mhaske |
| `owner-harsh.jpg` | Photo of Harsh Mhaske |
| `devotional.jpg` | Devotional / god image |
| `gallery-1.jpg` … `gallery-6.jpg` | Rath & fabrication work photos |

Recommended size: **1920×1080** for hero, **800×600** for gallery, **600×600** for owner photos.
